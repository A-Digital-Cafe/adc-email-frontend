# adc-email-frontend

Preset de frontend para la plataforma de correo ADC.

Contiene la app `adc-mail`: cliente de correo (micro-frontend React) con buzones,
editor de texto enriquecido, adjuntos, programación de envíos y banner de cuota.

Empareja con el preset `adc-email-backend` (servicio `email-service`). Reutiliza
los componentes `adc-mail-composer` y `adc-mail-viewer` de la UI Library.
